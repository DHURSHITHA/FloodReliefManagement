# Milestone 2 — Plan 1: SOS / Emergency Management Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let an affected person or camp official raise an SOS, have it routed to
the camp's linked hospital or police contact automatically, and track it through
acknowledgement to resolution — closing Group E (Response) of the requirements,
satisfying §16 acceptance criteria 15 and 16.

**Architecture:** A new `sos` module, sliced exactly like the `complaints` module it
sits beside — model / service / controller / routes / test in one folder — reusing
`resolveCampScope` for camp scoping, `recordAudit` for the audit trail, and the
existing Socket.IO channel for live updates. The one new idea is *routing
resolution*: the camp's `nearest_hospital_*` / `nearest_police_*` fields (already on
every camp since M1) are read once at creation and copied onto the SOS record, never
referenced live.

**Tech Stack:** Express 5, Mongoose 9, zod v4, React 19, MUI 9, TanStack Query v5,
Socket.IO, Vitest 4 + Supertest + `MongoMemoryReplSet`.

## Global Constraints

- **No hospital/police login accounts, permanently** (requirements §3.2). "Route to
  the hospital/police contact" means resolving and displaying that contact — never
  notifying an account that cannot exist.
- **`routed_to_name` / `routed_to_contact` are copied at creation, not referenced.**
  Editing a camp's hospital contact later must never change what a past SOS record
  says was called.
- **One module owns each collection; other modules reach it through that module's
  *service*, never its model** (M1 spec §3.2) — except the `dashboard` module's
  established precedent of importing models directly for read-only aggregation
  (`Camp`, `Beneficiary`, `Inventory`, `AffectedArea`, `FloodAlert` are all imported
  directly in `dashboard.service.js` today). SOS follows that same precedent for its
  dashboard counts.
- **Every closing status requires a note.** `resolved` and `closed` both need an
  account of what happened, mirroring the complaints module's rule that a closing
  status with no explanation is not a resolution.
- **No `.limit()` before an urgency sort.** A capped-then-sorted query can silently
  drop a critical SOS behind a higher document-insertion-order but lower-urgency one.
  Fetch the camp's/reporter's full result set, then sort — SOS volume is bounded by
  real emergencies, not registration-sized traffic.
- **Critical operations are audited** (`recordAudit`, spec §15) — SOS creation and
  every status transition.
- **Route ordering:** `/sos/mine` must be declared before `/sos/:id`, the same
  Express-5 literal-vs-param ordering rule already applied to `/complaints/mine` and
  `/registrations/priority`.
- **Design tokens:** `#FF6B00`/`#C44E00` brand orange, Lora (headings) + Public Sans
  (body), 14px card radius, `Box sx={{ display: 'grid' }}` rather than MUI `<Grid>`.
- Express 5: `req.query` is a getter — validated query results land on
  `req.validatedQuery`, never on `req.query` directly.
- zod v4: `.optional()` only skips `undefined`; an empty-string form field needs
  `z.preprocess((v) => (v === '' ? undefined : v), ...)` first.
- Test isolation: `clearDatabase()` + `syncIndexes()` in `beforeEach`, per
  `server/src/test/helpers.js`.

```js
// shared/src/schemas/sos.schema.js
import { z } from 'zod';

/**
 * Requirements §6.11 SOS / Emergency Management.
 *
 * Categories are the six the spec names, verbatim. Unlike complaints (§6.10,
 * which spells out its status list), §6.11 does not fix urgency or status —
 * both are design choices here. Urgency drives the "flagged by urgency"
 * dashboard ordering the spec asks for. Status widens complaints' three
 * working states by one (acknowledged, responding) because "track response
 * and resolution timeline" asks for more granularity than a query does.
 *
 * Hospital and police have no login accounts (out of scope permanently,
 * §3.2) — see sos.service.js for what "routed to" actually means as a result.
 */
export const SOS_CATEGORIES = [
  'medical',
  'security',
  'food_shortage',
  'water_shortage',
  'missing_person',
  'other',
];

export const SOS_URGENCY = ['critical', 'high', 'medium', 'low'];

export const SOS_STATUSES = ['open', 'acknowledged', 'responding', 'resolved', 'closed'];

/** Statuses that mean nobody is actively responding any more. */
export const CLOSED_SOS_STATUSES = ['resolved', 'closed'];

export const createSosSchema = z.object({
  camp_id: z.string().regex(/^[0-9a-fA-F]{24}$/, 'Choose the camp this is about.'),
  category: z.enum(SOS_CATEGORIES, { message: 'Choose a category.' }),
  urgency: z.enum(SOS_URGENCY, { message: 'Choose how urgent this is.' }),
  description: z
    .string()
    .trim()
    .min(10, 'Describe the emergency in at least 10 characters.')
    .max(2000, 'Keep it under 2000 characters.'),
  location: z
    .string()
    .trim()
    .min(2, 'Say roughly where — e.g. "block 4 tents" or "near the food line".')
    .max(200),
});

/**
 * A transition off "open". A closing status with no account of what
 * happened is not a resolution — the same rule complaints enforces for both
 * of its closing statuses (resolved and rejected), applied here to both of
 * SOS's (resolved and closed).
 */
export const updateSosSchema = z.object({
  status: z.enum(['acknowledged', 'responding', 'resolved', 'closed'], { message: 'Choose a status.' }),
  note: z.preprocess(
    (v) => (v === '' ? undefined : v),
    z.string().trim().max(2000).optional(),
  ),
}).superRefine((val, ctx) => {
  if (CLOSED_SOS_STATUSES.includes(val.status) && !val.note) {
    ctx.addIssue({
      code: 'custom',
      path: ['note'],
      message: 'Say what was done before closing this.',
    });
  }
});

export const listSosQuerySchema = z.object({
  camp_id: z.preprocess(
    (v) => (v === '' ? undefined : v),
    z.string().regex(/^[0-9a-fA-F]{24}$/, 'Invalid camp id.').optional(),
  ),
  status: z.preprocess(
    (v) => (v === '' ? undefined : v),
    z.enum(SOS_STATUSES).optional(),
  ),
});
```

```js
// shared/src/sosOrder.js
import { CLOSED_SOS_STATUSES, SOS_URGENCY } from './schemas/sos.schema.js';

/**
 * Urgency ordering for the Emergency dashboard, per requirements §6.11:
 * "Display SOS immediately on the Admin dashboard, flagged by urgency."
 *
 * Deliberately separate from complaint priority or registration priority —
 * an SOS at "medium" urgency is not on the same scale as a complaint at
 * "normal" priority and must never be compared against one.
 */
export function urgencyRank(urgency) {
  const rank = SOS_URGENCY.indexOf(urgency);
  return rank >= 0 ? rank : SOS_URGENCY.length;
}

/** Still-open work before closed work; most urgent first within each; newest first after that. */
export function bySosPriority(a, b) {
  const openA = CLOSED_SOS_STATUSES.includes(a.status) ? 1 : 0;
  const openB = CLOSED_SOS_STATUSES.includes(b.status) ? 1 : 0;
  if (openA !== openB) return openA - openB;

  const diff = urgencyRank(a.urgency) - urgencyRank(b.urgency);
  if (diff !== 0) return diff;

  return new Date(b.createdAt) - new Date(a.createdAt);
}
```

```js
// server/src/core/idGenerator.js — full replacement
import mongoose from 'mongoose';

const counterSchema = new mongoose.Schema(
  { _id: String, seq: { type: Number, default: 0 } },
  { collection: 'counters' }
);

const Counter = mongoose.model('Counter', counterSchema);

/**
 * Atomic $inc + upsert — the only race-free way to hand out sequential
 * human-facing codes under concurrent requests (spec section 4.2). Counting
 * documents races under concurrent submission; this does not.
 */
async function nextCode(counterKey, prefix, session) {
  const counter = await Counter.findOneAndUpdate(
    { _id: counterKey },
    { $inc: { seq: 1 } },
    { new: true, upsert: true, session }
  );
  return `${prefix}-${1000 + counter.seq}`;
}

export const nextBeneficiaryCode = (session) => nextCode('beneficiary_code', 'BEN', session);

/** The "Complaint ID" of §6.10. */
export const nextComplaintCode = (session) => nextCode('complaint_code', 'CMP', session);

/** The SOS record id implied by §6.11's field list. */
export const nextSosCode = (session) => nextCode('sos_code', 'SOS', session);
```

```js
import mongoose from 'mongoose';
```

```js
const sosSchema = new mongoose.Schema(
  {
    sos_code: { type: String, required: true, unique: true },
    reported_by: { type: mongoose.Schema.Types.ObjectId, ref: 'User', required: true, index: true },
    reporter_role: { type: String, required: true },
    camp_id: { type: mongoose.Schema.Types.ObjectId, ref: 'Camp', required: true, index: true },
    category: { type: String, enum: SOS_CATEGORIES, required: true },
    urgency: { type: String, enum: SOS_URGENCY, required: true },
    description: { type: String, required: true },
    location: { type: String, required: true },
    status: { type: String, enum: SOS_STATUSES, default: 'open', index: true },
    routed_to_type: { type: String, enum: ['hospital', 'police', 'camp_admin'], required: true },
    routed_to_name: { type: String, required: true },
    routed_to_contact: { type: String, required: true },
    resolution: { type: String, default: '' },
    resolved_at: { type: Date, default: null },
    timeline: [
      {
        _id: false,
        status: { type: String, enum: SOS_STATUSES, required: true },
        actor_id: { type: mongoose.Schema.Types.ObjectId, ref: 'User', required: true },
        note: { type: String, default: '' },
        at: { type: Date, required: true },
      },
    ],
  },
  { timestamps: true, collection: 'sos_requests' }
);

sosSchema.index({ camp_id: 1, status: 1, urgency: 1 });
// The admin's cross-camp open list.
sosSchema.index({ status: 1, createdAt: -1 });

sosSchema.methods.toSafeJSON = function toSafeJSON() {
  return {
    id: this._id.toString(),
    sos_code: this.sos_code,
    reported_by: this.reported_by.toString(),
    reporter_role: this.reporter_role,
    camp_id: this.camp_id.toString(),
    category: this.category,
    urgency: this.urgency,
    description: this.description,
    location: this.location,
    status: this.status,
    routed_to_type: this.routed_to_type,
    routed_to_name: this.routed_to_name,
    routed_to_contact: this.routed_to_contact,
    resolution: this.resolution,
    resolved_at: this.resolved_at,

    updatedAt: this.updatedAt,
  };
};
```

```js
// server/src/modules/sos/sos.service.js
import { CLOSED_SOS_STATUSES, bySosPriority } from '@frp/shared';
import { SosRequest } from './sos.model.js';
import { User } from '../auth/user.model.js';
import { AppError } from '../../core/errors.js';
import { nextSosCode } from '../../core/idGenerator.js';
import { recordAudit } from '../audit/audit.service.js';
import { createNotification } from '../notifications/notifications.service.js';
import { resolveCampScope } from '../intake/intake.service.js';
import { getCampById } from '../camps/camps.service.js';
import { emitSosUpdate } from '../../core/socket.js';

/**
 * SOS / Emergency management, requirements §6.11.
 *
 * Hospital and police accounts do not exist (out of scope permanently, per
 * requirements §3.2), so "route to the hospital/police contact" cannot mean
 * notifying a login. It means: resolve that camp's linked contact, stamp it
 * onto the record so whoever picks this up sees a name and a number to call,
 * and track what happens next to resolution.
 */
function resolveRouting(camp, category) {
  if (category === 'medical') {
    return {
      routed_to_type: 'hospital',
      routed_to_name: camp.nearest_hospital_name,
      routed_to_contact: camp.nearest_hospital_contact,
    };
  }
  if (category === 'security') {
    return {
      routed_to_type: 'police',
      routed_to_name: camp.nearest_police_name,
      routed_to_contact: camp.nearest_police_contact,
    };
  }
  return {
    routed_to_type: 'camp_admin',
    routed_to_name: `${camp.name} camp administration`,
    routed_to_contact: camp.official_contact_number || 'Not on file — contact the camp directly.',
  };
}

export async function raiseSos({ camp_id, category, urgency, description, location }, { actorId, actorRole, ip }) {
  const camp = await getCampById(camp_id);
  const routing = resolveRouting(camp, category);
  const now = new Date();

  const sos = await SosRequest.create({
    sos_code: await nextSosCode(),
    reported_by: actorId,
    reporter_role: actorRole,
    camp_id,
    category,
    urgency,
    description,
    location,
    ...routing,
    timeline: [{ status: 'open', actor_id: actorId, note: '', at: now }],
  });

  await notifyOnRaise(sos);
  emitSosUpdate(sos.camp_id, { sosId: sos._id.toString(), status: sos.status, urgency: sos.urgency });

  await recordAudit({
    actor_id: actorId, actor_role: actorRole, action: 'sos.create',
    module: 'sos', record_id: sos._id,
    after: { sos_code: sos.sos_code, category, urgency, routed_to_type: routing.routed_to_type }, ip,
  });

  return sos;
}

/**
 * §14: admins hear about every SOS; camp officials hear about emergencies at
 * their own camp. Both — an SOS is not routine traffic the way a complaint
 * is, and §6.11 asks for it on the admin dashboard "immediately".
 */
async function notifyOnRaise(sos) {
  const [admins, officials] = await Promise.all([
    User.find({ role: 'admin', status: 'active' }),
    User.find({ role: 'camp_official', status: 'active', assigned_camp_ids: sos.camp_id }),
  ]);

  const message = `${sos.sos_code}: a ${sos.urgency} ${sos.category.replace('_', ' ')} emergency was raised, routed to ${sos.routed_to_name}.`;

  await Promise.all(
    [...admins, ...officials].map((u) => createNotification({
      user_id: u._id, type: 'sos', ref_id: sos._id, message,
    }))
  );
}

/**
 * What the reporter sees: their own SOS requests, most urgent-and-open
 * first. Not `.limit()`ed before the sort — a person reports few enough of
 * these that truncation risk does not apply, and correctness (nothing
 * urgent silently missing) matters more here than anywhere else in the app.
 */
export async function listMySos(actorId) {
  const mine = await SosRequest.find({ reported_by: actorId });
  return mine.sort(bySosPriority);
}

/** The Emergency dashboard: camp-scoped for officials, all camps for admins. */
export async function listSos({ actorRole, actorCampIds, selectedCampId, status }) {
  const filter = { ...resolveCampScope({ actorRole, actorCampIds, selectedCampId }).filter };
  if (status) filter.status = status;
  const requests = await SosRequest.find(filter);
  return requests.sort(bySosPriority);
}

export async function transitionSos(sosId, { status, note }, { actorId, actorRole, actorCampIds, ip }) {
  const scope = resolveCampScope({ actorRole, actorCampIds });

  const sos = await SosRequest.findById(sosId);
  if (!sos) throw AppError.notFound('No SOS request with that id.');
  if (!scope.allows(sos.camp_id)) {
    throw AppError.forbidden('That SOS request is at a camp you are not assigned to.');
  }

  const before = { status: sos.status };
  const now = new Date();
  sos.status = status;
  if (CLOSED_SOS_STATUSES.includes(status) && note) sos.resolution = note;
  sos.resolved_at = CLOSED_SOS_STATUSES.includes(status) ? now : null;
  sos.timeline.push({ status, actor_id: actorId, note: note ?? '', at: now });
  await sos.save();

  // Tell the person who raised it — the same reasoning as complaints: an
  // emergency nobody hears back on reads as one nobody is handling.
  await createNotification({
    user_id: sos.reported_by,
    type: 'sos_update',
    ref_id: sos._id,
    message: `${sos.sos_code} is now ${status.replace('_', ' ')}.`,
  });
  emitSosUpdate(sos.camp_id, { sosId: sos._id.toString(), status: sos.status, urgency: sos.urgency });

  await recordAudit({
    actor_id: actorId, actor_role: actorRole, action: 'sos.transition',
    module: 'sos', record_id: sos._id,
    before, after: { status: sos.status }, ip,
  });

  return sos;
}

/** Requirements §6.16 Emergency dashboard area: open, medical, security, resolved. */
export async function getSosDashboardCounts() {
  const [open, medical, security, resolved] = await Promise.all([
    SosRequest.countDocuments({ status: { $nin: CLOSED_SOS_STATUSES } }),
    SosRequest.countDocuments({ category: 'medical', status: { $nin: CLOSED_SOS_STATUSES } }),
    SosRequest.countDocuments({ category: 'security', status: { $nin: CLOSED_SOS_STATUSES } }),
    SosRequest.countDocuments({ status: 'resolved' }),
  ]);
  return { open, medical, security, resolved };
}
```

```js
import { api } from './client.js';

export function useRaiseSos() {
  const qc = useQueryClient();
  return useMutation({

    onSuccess: () => qc.invalidateQueries({ queryKey: ['sos'] }),

export function useSosRequests(params = {}) {
```

```js
// client/src/api/socket.js — append
/**
 * Subscribe to sos:update for the lifetime of the calling component. On
 * receipt this invalidates both the SOS queries and the dashboard summary —
 * §6.11 asks for SOS to display "immediately" on the admin dashboard, and
 * the summary has no other refresh trigger of its own.
 */
export function useLiveSosUpdates() {
  const qc = useQueryClient();

  useEffect(() => {
    socket.connect();
    const onUpdate = () => {
      qc.invalidateQueries({ queryKey: ['sos'] });
      qc.invalidateQueries({ queryKey: ['dashboard'] });
    };
    socket.on('sos:update', onUpdate);
    return () => {
      socket.off('sos:update', onUpdate);
      socket.disconnect();
    };
  }, [qc]);
}
```

```jsx
import { useState } from 'react';
import {
  Alert, Box, Button, Card, CardContent, MenuItem, Stack, TextField, Typography,
} from '@mui/material';
import { SOS_CATEGORIES, SOS_URGENCY } from '@frp/shared';
import { useRaiseSos, useMySos } from '../../api/sos.js';
import { useCamps } from '../../api/camps.js';
import { useMyRegistration } from '../../api/registration.js';
import { toFormErrors } from '../../api/client.js';
import { SosCard } from './SosCard.jsx';

const CATEGORY_LABELS = {
  medical: 'Medical', security: 'Security', food_shortage: 'Food shortage',
  water_shortage: 'Water shortage', missing_person: 'Missing person', other: 'Other emergency',
};

/**
 * Where an affected person reports an emergency and watches what happens to
 * it. Raising and tracking share a screen for the same reason the query page
 * does: the first thing anyone wants to know after sending one is whether
 * someone is coming.
 */
export function RaiseSosPage() {
  const { data: registration } = useMyRegistration();
  const { data: camps = [] } = useCamps();
  const { data: mine = [], isLoading } = useMySos();
  const raise = useRaiseSos();

  const [values, setValues] = useState({ camp_id: '', category: 'medical', urgency: 'high', location: '', description: '' });
  const [error, setError] = useState(null);
  const [sent, setSent] = useState(null);

  const campId = values.camp_id || registration?.beneficiary?.camp_id || '';
  const change = (f) => (e) => setValues((v) => ({ ...v, [f]: e.target.value }));

  async function onSubmit(e) {
    e.preventDefault();
    setError(null);
    setSent(null);
    try {
      const created = await raise.mutateAsync({ ...values, camp_id: campId });
      setSent(`Sent as ${created.sos_code}, routed to ${created.routed_to_name} (${created.routed_to_contact}).`);
      setValues((v) => ({ ...v, location: '', description: '' }));
    } catch (err) {
      setError(toFormErrors(err).message);
    }
  }

  return (
    <Box sx={{ display: 'grid', gridTemplateColumns: { xs: '1fr', md: '1fr 1fr' }, gap: 4, alignItems: 'start' }}>
      <Card>
        <CardContent>
          <Typography variant="h5" sx={{ fontFamily: '"Lora", Georgia, serif', fontWeight: 600, mb: 0.5 }}>
            Report an emergency
          </Typography>
          <Typography variant="body2" color="text.secondary" sx={{ mb: 2 }}>
            This reaches the camp's linked hospital or police contact immediately.
          </Typography>

          {error && <Alert severity="error" sx={{ mb: 2 }}>{error}</Alert>}
          {sent && <Alert severity="success" sx={{ mb: 2 }}>{sent}</Alert>}

          <Box component="form" onSubmit={onSubmit} noValidate>
            <TextField select label="Camp" value={campId} onChange={change('camp_id')}>
              {camps.map((c) => <MenuItem key={c.id} value={c.id}>{c.name}</MenuItem>)}
            </TextField>

            <TextField select label="What kind of emergency?" value={values.category} onChange={change('category')}>
              {SOS_CATEGORIES.map((c) => (
                <MenuItem key={c} value={c}>{CATEGORY_LABELS[c] ?? c}</MenuItem>
              ))}
            </TextField>

            <TextField select label="How urgent?" value={values.urgency} onChange={change('urgency')}>
              {SOS_URGENCY.map((u) => <MenuItem key={u} value={u}>{u}</MenuItem>)}
            </TextField>

            <TextField
              label="Where"
              value={values.location}
              onChange={change('location')}
              placeholder="e.g. block 4 tents, near the food line"
            />

            <TextField
              label="Describe the emergency"
              value={values.description}
              onChange={change('description')}
              placeholder="What is happening, and to whom?"
              multiline
              minRows={4}
            />

            <Button
              type="submit" variant="contained" color="error" fullWidth sx={{ mt: 2 }}
              disabled={
                raise.isPending || !campId
                || values.description.trim().length < 10
                || values.location.trim().length < 2
              }
            >
              {raise.isPending ? 'Sending…' : 'Send emergency alert'}
            </Button>
          </Box>
        </CardContent>
      </Card>

      <Box>
        <Typography sx={{ fontWeight: 600, mb: 1.5 }}>Your reports</Typography>
        <Stack spacing={1.5}>
          {mine.map((s) => <SosCard key={s.id} sos={s} />)}
          {!isLoading && mine.length === 0 && (
            <Typography color="text.secondary" variant="body2">
              You have not reported an emergency.
            </Typography>
          )}
        </Stack>
      </Box>
    </Box>
  );
}
```

```jsx
// client/src/features/sos/SosDashboardPage.jsx
import { useState } from 'react';
import {
  Alert, Box, Button, MenuItem, Stack, TextField, Typography,
} from '@mui/material';
import { SOS_STATUSES, CLOSED_SOS_STATUSES } from '@frp/shared';
import { useSosRequests, useTransitionSos } from '../../api/sos.js';
import { useLiveSosUpdates } from '../../api/socket.js';
import { toFormErrors } from '../../api/client.js';
import { CampBar } from '../../camps/CampBar.jsx';
import { useCampScope } from '../../camps/CampScope.jsx';
import { SosCard, STATUS_LABELS } from './SosCard.jsx';

const TRANSITIONABLE = SOS_STATUSES.filter((s) => s !== 'open');

/** The response controls an official or admin gets on each SOS request. */
function ResponseControls({ sos }) {
  const transition = useTransitionSos();
  const [status, setStatus] = useState(sos.status === 'open' ? 'acknowledged' : sos.status);
  const [note, setNote] = useState('');
  const [error, setError] = useState(null);

  const closing = CLOSED_SOS_STATUSES.includes(status);
  const unchanged = status === sos.status;

  async function save() {
    setError(null);
    try {
      await transition.mutateAsync({ id: sos.id, status, note: note || undefined });
      setNote('');
    } catch (err) {
      const { message, fields } = toFormErrors(err);
      setError(fields.note ?? message);
    }
  }

  return (
    <Box sx={{ mt: 2, pt: 2, borderTop: '1px solid #F0E7DE' }}>
      {error && <Alert severity="error" sx={{ mb: 2 }}>{error}</Alert>}

      <Box sx={{ display: 'flex', gap: 1.5, alignItems: 'flex-start', flexWrap: 'wrap' }}>
        <TextField
          select size="small" label="Status" value={status}
          onChange={(e) => setStatus(e.target.value)} sx={{ minWidth: 180, mb: 0 }}
        >
          {TRANSITIONABLE.map((s) => (
            <MenuItem key={s} value={s}>{STATUS_LABELS[s] ?? s}</MenuItem>
          ))}
        </TextField>

        <Button variant="contained" size="medium" onClick={save} disabled={transition.isPending || unchanged}>
          {transition.isPending ? 'Saving…' : 'Update'}
        </Button>
      </Box>

      {closing && (
        <TextField
          label="What was done"
          value={note}
          onChange={(e) => setNote(e.target.value)}
          placeholder="Required before this can be closed."
          multiline minRows={2}
          sx={{ mt: 2 }}
        />
      )}
    </Box>
  );
}

/**
 * The Emergency dashboard: everything raised at the camp an official is
 * working in, or every camp for an admin. Shares the camp bar with the other
 * operational screens, and updates live — an emergency someone else just
 * acknowledged should not sit in the list looking unattended.
 */
export function SosDashboardPage() {
  useLiveSosUpdates();
  const { params, campId } = useCampScope();
  const [statusFilter, setStatusFilter] = useState('');
  const { data: requests = [], isLoading } = useSosRequests({
    ...params,
    ...(statusFilter ? { status: statusFilter } : {}),
  });

  const open = requests.filter((s) => !CLOSED_SOS_STATUSES.includes(s.status)).length;

  return (
    <Box>
      <CampBar />

      <Box sx={{ display: 'flex', alignItems: 'center', gap: 2, mb: 2, flexWrap: 'wrap' }}>
        <Box>
          <Typography variant="h5" sx={{ fontFamily: '"Lora", Georgia, serif', fontWeight: 600 }}>
            Emergency
          </Typography>
          <Typography variant="body2" color="text.secondary">
            {open} still need a response.
          </Typography>
        </Box>
        <TextField
          select size="small" label="Filter by status" value={statusFilter}
          onChange={(e) => setStatusFilter(e.target.value)}
          sx={{ minWidth: 180, ml: 'auto', mb: 0 }}
        >
          <MenuItem value="">All statuses</MenuItem>
          {SOS_STATUSES.map((s) => (
            <MenuItem key={s} value={s}>{STATUS_LABELS[s] ?? s}</MenuItem>
          ))}
        </TextField>
      </Box>

      <Stack spacing={2} sx={{ maxWidth: 720 }}>
        {requests.map((s) => (
          <SosCard key={s.id} sos={s}>
            <ResponseControls sos={s} />
          </SosCard>
        ))}
        {!isLoading && requests.length === 0 && (
          <Typography color="text.secondary">
            {campId ? 'Nothing has been reported at this camp.' : 'Nothing has been reported yet.'}
          </Typography>
        )}
      </Stack>
    </Box>
  );
}
```

```js
// scripts/verify-sos.mjs
/**
 * Dev check against the running server for SOS / Emergency management
 * (§6.11), proving routing resolution and §16 criteria 15–16 live.
 *
 * Run: node --env-file=.env scripts/verify-sos.mjs
 */
import mongoose from 'mongoose';
import { signAccessToken } from '../server/src/core/tokens.js';

const BASE = process.env.VERIFY_BASE_URL ?? 'http://localhost:4000';
await mongoose.connect(process.env.MONGODB_URI);
const users = mongoose.connection.collection('users');

const official = await users.findOne({ role: 'camp_official', status: 'active', 'assigned_camp_ids.0': { $exists: true } });
const person = await users.findOne({ role: 'affected_person', status: 'active' });
const admin = await users.findOne({ role: 'admin', status: 'active' });
const donor = await users.findOne({ role: 'donor', status: 'active' });

const tokenFor = (u) => signAccessToken({ _id: u._id, role: u.role, status: u.status, assigned_camp_ids: u.assigned_camp_ids ?? [] });
const hdrs = (u) => ({ Authorization: `Bearer ${tokenFor(u)}`, 'Content-Type': 'application/json' });
const campId = official.assigned_camp_ids[0].toString();

async function call(label, u, method, path, body) {
  const res = await fetch(`${BASE}${path}`, { method, headers: hdrs(u), ...(body ? { body: JSON.stringify(body) } : {}) });
  const json = await res.json().catch(() => ({}));
  return { label, status: res.status, json };
}
const show = (r, extra = '') => console.log(`${r.label.padEnd(50)} ${r.status}  ${extra || r.json.error?.message || ''}`);

console.log('--- routing resolution (§16 #16) ---');
const raised = await call('person POST /sos (medical)', person, 'POST', '/api/sos', {
  camp_id: campId, category: 'medical', urgency: 'critical',
  description: 'Live verification: a woman in tent 4 needs medical attention.', location: 'Tent 4',
});
show(raised, `${raised.json.sos?.sos_code} routed to ${raised.json.sos?.routed_to_name} (${raised.json.sos?.routed_to_contact})`);

show(await call('donor POST /sos', donor, 'POST', '/api/sos', {
  camp_id: campId, category: 'medical', urgency: 'high', description: 'Donors may not raise SOS requests.', location: 'x',
}));

console.log('--- dashboard and tracking to resolution (§16 #15) ---');
const id = raised.json.sos?.id;
show(await call('official GET /sos (their camp)', official, 'GET', `/api/sos?camp_id=${campId}`),
  `${(await call('x', official, 'GET', `/api/sos?camp_id=${campId}`)).json.sos_requests?.length} visible`);

if (id) {
  show(await call('official PATCH -> acknowledged', official, 'PATCH', `/api/sos/${id}`, { status: 'acknowledged' }));
  show(await call('official PATCH -> resolved, no note', official, 'PATCH', `/api/sos/${id}`, { status: 'resolved' }), 'expect 400');
  const done = await call('official PATCH -> resolved, with note', official, 'PATCH', `/api/sos/${id}`, {
    status: 'resolved', note: 'Taken to the medical tent by 14:05, stable.',
  });
  show(done, done.json.sos?.resolved_at ? 'resolved_at stamped' : '');
}

const summary = await call('admin GET dashboard summary', admin, 'GET', '/api/dashboard/summary');
console.log(`Emergency area: ${JSON.stringify(summary.json.emergency)}`);

const notifs = await call('reporter notifications', person, 'GET', '/api/notifications');
console.log(`reporter heard back: ${(notifs.json.notifications ?? []).filter((n) => n.type === 'sos_update').map((n) => n.message).join(' | ') || 'none'}`);

await mongoose.disconnect();
```
